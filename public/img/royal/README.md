# Portrait of His Majesty

Save the official portrait here as `hm-king.jpg` (or .jpeg/.png/.webp).
`components/RoyalPortrait.tsx` picks it up automatically at build time;
until then the home page shows the framed placeholder.

Portrait orientation, roughly 3:4. It renders at 280px wide on desktop,
so ~880x1170 is plenty.

Use an officially released image and confirm ABAC has permission to
publish it.
